Webhooks are configured in the [dashboard](https://app.urtentic.com) by an organization owner or admin. There's no API for it.

## Where events are sent

Each event is sent to one URL and signed with one secret. Urtentic picks them per workflow:

| Setting | Used when |
|---|---|
| **Workflow URL** | The verification's workflow has its own webhook URL |
| **Organization default URL** | The workflow has no URL of its own |
| **Workflow secret** | The workflow has its own secret, created when you rotate it (see below) |
| **Organization default secret** | The workflow has no secret of its own |

The URL and the secret are chosen independently. A workflow with its own URL but no secret of its own is signed with the organization default secret.

If neither the workflow nor the organization has a URL, no events are sent.

## Set the webhook URL

<Steps>
  <Step title="Open the workflow's webhook settings">
    In the dashboard, go to **Integrations**, choose the workflow under **All Integrations**, and click **Webhooks**.
  </Step>
  <Step title="Choose where to set it">
    - **This Workflow**: events for this workflow only.
    - **Organization Default**: events for every workflow that doesn't have its own URL.
  </Step>
  <Step title="Save the URL">
    Enter your endpoint, for example `https://api.yourapp.com/webhooks/urtentic`, and click **Save Url**. The URL must start with `https://`.
  </Step>
</Steps>

## Get the signing secret

Secrets are random 32-byte keys, shown Base64-encoded.

**Workflow secret.** On the **This Workflow** tab, click the refresh icon next to **Secret** to create a secret for this workflow. Click the eye icon to show it, then copy it to your server. Until you do this, the field reads **Using organisation default** and the workflow's events are signed with the organization default secret.

**Organization default secret.** This is created together with your API keys. The **Organization Default** tab shows it masked, and the dashboard currently has no way to reveal or copy it.

<Note>
To verify signatures today, create a workflow secret for each workflow you receive events from. That's the secret you can copy.
</Note>

## Rotate secrets

- **Workflow secret:** click the refresh icon again. The new secret takes effect immediately for that workflow's events, so update your server straight away.
- **Organization default secret:** rotating your API keys on the **Integrations** page also replaces the organization default secret. Any workflow without its own secret is signed with the new one from then on.

<Warning>
There's no overlap period after a rotation. Events signed with the new secret fail verification until your server has it, and failed deliveries aren't retried.
</Warning>

## Verify the signature

Compute the HMAC-SHA256 of the **raw** request body, using the Base64-decoded secret as the key. Compare it, as lowercase hex, with the `x-urtentic-signature` header using a constant-time comparison. `x-urtentic-timestamp` isn't part of the signature.

<CodeGroup>

```javascript Node.js (Express)
const express = require("express");
const crypto = require("crypto");

const app = express();

// Keep the raw body: the signature is computed over the exact bytes Urtentic sent.
app.post("/webhooks/urtentic", express.raw({ type: "application/json" }), (req, res) => {
  const signature = req.get("x-urtentic-signature") ?? "";
  const expected = crypto
    .createHmac("sha256", Buffer.from(process.env.URTENTIC_WEBHOOK_SECRET, "base64"))
    .update(req.body)
    .digest("hex");

  const valid =
    signature.length === expected.length &&
    crypto.timingSafeEqual(Buffer.from(signature, "hex"), Buffer.from(expected, "hex"));
  if (!valid) {
    return res.status(401).send("Invalid signature");
  }

  const event = JSON.parse(req.body.toString("utf8"));
  // Store the event and process it asynchronously, then acknowledge quickly.
  console.log(`Received ${event.eventName} for ${event.resource}`);
  return res.sendStatus(200);
});

app.listen(3000);
```

```python Python (Flask)
import base64
import hashlib
import hmac
import json
import os

from flask import Flask, request

app = Flask(__name__)
SECRET = base64.b64decode(os.environ["URTENTIC_WEBHOOK_SECRET"])


@app.post("/webhooks/urtentic")
def urtentic_webhook():
    raw_body = request.get_data()  # the exact bytes Urtentic sent
    expected = hmac.new(SECRET, raw_body, hashlib.sha256).hexdigest()
    if not hmac.compare_digest(request.headers.get("x-urtentic-signature", ""), expected):
        return "Invalid signature", 401

    event = json.loads(raw_body)
    # Store the event and process it asynchronously, then acknowledge quickly.
    app.logger.info("Received %s for %s", event["eventName"], event["resource"])
    return "", 200
```

```php PHP
<?php
$rawBody = file_get_contents('php://input'); // the exact bytes Urtentic sent
$secret = base64_decode(getenv('URTENTIC_WEBHOOK_SECRET'));
$expected = hash_hmac('sha256', $rawBody, $secret);
```

```java Java (Spring Boot)
import java.nio.charset.StandardCharsets;
import java.security.MessageDigest;
import java.util.Base64;
import java.util.HexFormat;
import javax.crypto.Mac;
import javax.crypto.spec.SecretKeySpec;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;

@RestController
public class UrtenticWebhookController {

    @Value("${urtentic.webhook-secret}")
    private String webhookSecret;

    @PostMapping("/webhooks/urtentic")
    public ResponseEntity<Void> receive(@RequestHeader(value = "x-urtentic-signature", defaultValue = "") String signature,
                                        @RequestBody byte[] rawBody) throws Exception {
        Mac mac = Mac.getInstance("HmacSHA256");
        mac.init(new SecretKeySpec(Base64.getDecoder().decode(webhookSecret), "HmacSHA256"));
        String expected = HexFormat.of().formatHex(mac.doFinal(rawBody));

        if (!MessageDigest.isEqual(expected.getBytes(StandardCharsets.US_ASCII),
                signature.getBytes(StandardCharsets.US_ASCII))) {
            return ResponseEntity.status(401).build();
        }
        // Store the event and process it asynchronously, then acknowledge quickly.
        return ResponseEntity.ok().build();
    }
}
```

## Troubleshooting

| Problem | Check |
|---|---|
| No events arrive | A URL is set on the workflow or as the organization default, it starts with `https://`, and it's reachable from the internet |
| Every signature fails | You're using the secret for the right source: the workflow secret if the workflow has one, otherwise the organization default |
| Signatures started failing | A secret was rotated, either the workflow secret or the organization default through an API key rotation |
| Some signatures fail | You're hashing the raw body, not re-serialized JSON |
| An event is missing | Failed deliveries aren't retried. Check the verification with `GET /verifications/{verificationId}/status`. |
